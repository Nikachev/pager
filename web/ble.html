Connect as a keyboard

Pager exposes the standard Bluetooth HID Keyboard and Battery services. The development battery value is fixed at 13%. Pair it from the operating system instead of a browser.

  1. Open Bluetooth settings on macOS or Android.
  2. Select the active device, for example Pager 1.
  3. Complete pairing and confirm that it appears as a keyboard.
Use the autonomous USB control page to select slots, change the common Pager name, clear bonds, and send a keyboard test.
